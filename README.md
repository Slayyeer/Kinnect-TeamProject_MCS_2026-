# Kinnect

**Kinnect** — приложение для совместного просмотра видео с друзьями. Участники заходят в общее «лобби», и у всех одновременно ставится пауза, перематывается и запускается одно и то же видео. Рядом с плеером — чат.

## Какую проблему решаем

Когда друзья смотрят фильм на расстоянии (по созвону), видео у всех идёт вразнобой: приходится считать «3, 2, 1 — пуск», а после каждой паузы всё сбивается. Kinnect держит видео у всех участников на одной секунде.

## Основные возможности (план)

- регистрация по почте с подтверждением;
- друзья и приглашения;
- лобби (открытые и закрытые);
- общие пуск, пауза и перемотка;
- чат с реакциями и таймкодами;
- видео с YouTube, Rutube, VK Видео, по прямой ссылке или из своего файла;
- сайт, Android-приложение и программа для компьютера.
