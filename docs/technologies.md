# Выбор технологий

## 1. Что нужно от серверной части

1. Вход по почте с подтверждением и восстановлением пароля.
2. База данных, которая **сама присылает изменения** всем участникам: синхронизации видео нужны обновления за доли секунды.
3. Правила доступа: чужие данные и чужие лобби недоступны.
4. Хостинг сайта.
5. Бесплатно (учебный проект).

## 2. Варианты

| Критерий | Свой сервер (Node.js + PostgreSQL + WebSocket) | Firebase (Auth + Firestore + Hosting) |
|---|---|---|
| Вход по почте, письма, сброс пароля | писать самим, нужен почтовый сервис | готово (Firebase Authentication) |
| Обновления в реальном времени | свой WebSocket-сервер | встроено: подписка на документ |
| Безопасность | проверки в коде сервера | декларативные правила `firestore.rules` |
| Хостинг | арендовать сервер, настроить HTTPS | Firebase Hosting, HTTPS сразу |
| Стоимость | аренда сервера | бесплатный тариф Spark |
| Работа с Android и компьютером | своё API | одни и те же SDK для всех платформ |

**Выбор: Firebase.** Он закрывает пункты 1–4 без своего сервера, а время мы тратим на главное — синхронизацию.

## 3. Ограничения бесплатного тарифа (Spark)

- Firestore: ограничено число чтений и записей в сутки — поэтому синхронизация пишет в базу только события (пуск, пауза, перемотка), а не позицию каждую секунду.
- Хранилище файлов (Cloud Storage) на бесплатном тарифе недоступно — **видеофайлы не загружаем**: каждый выбирает у себя копию файла, синхронизируется только управление.
- Фото профиля храним уменьшенным (256×256) прямо в профиле.

## 4. Зачем нужен прокси на Cloudflare

Многие сайты запрещают показывать себя внутри чужой страницы (заголовки `X-Frame-Options` и `Content-Security-Policy: frame-ancestors`). Браузер не даёт обойти это со стороны страницы — снять заголовки может только посредник между сайтом и пользователем.

**Cloudflare Workers** — бесплатный тариф (до 100 000 запросов в сутки), запуск кода близко к пользователю, без своего сервера. Ограничение: 10 мс процессорного времени на запрос, поэтому обработка страниц должна быть лёгкой.

В Android и программе для компьютера прокси не нужен: там есть свой встроенный браузер.

## 5. Итоговый набор

| Часть | Технология |
|---|---|
| Сайт | HTML, CSS, JavaScript (модули, без сборщика) |
| Вход и база | Firebase Authentication, Cloud Firestore |
| Хостинг сайта | Firebase Hosting |
| Прокси | Cloudflare Workers |
| Android | Java, WebView (`androidx.webkit`) |
| Программа для компьютера | Electron |
| Автосборка | GitHub Actions |
