# Анализ похожих сервисов

Рассмотрены три популярных сервиса совместного просмотра. Данные — по открытым описаниям сервисов; перед защитой стоит самим зайти и проверить, что ничего не поменялось.

## 1. Сравнение

| Критерий | Teleparty | Rave | Watch2Gether | **Kinnect** |
|---|---|---|---|---|
| Как работает | расширение для браузера | приложение | сайт | сайт + Android + программа для компьютера |
| Телефон | нет (только браузер на компьютере) | да | через мобильный браузер | да, отдельное приложение |
| YouTube | да | да | да | да |
| Rutube, VK Видео | нет | нет | нет | **да** |
| Свой видеофайл | нет | частично | нет | **да** (у каждого своя копия) |
| Netflix и другие подписки | да, нужна подписка у каждого | частично | нет | нет (защищённые видео не поддерживаем) |
| Чат | да | да, есть голос | да | да, с реакциями и таймкодами |
| Друзья | нет | да | нет (комнаты по ссылке) | да |
| Регистрация | не нужна | нужна | не обязательна | нужна (защита данных) |
| Язык интерфейса | английский | многоязычный | многоязычный | русский |

## 2. Что берём у других

- **Watch2Gether:** простое создание комнаты, приглашение по ссылке.
- **Rave:** друзья и мобильное приложение.
- **Teleparty:** чат сбоку от видео, не мешает просмотру.

## 3. Чем Kinnect отличается

1. Поддержка российских видеосервисов (Rutube, VK Видео).
2. Можно смотреть свой файл, ничего никуда не загружая.
3. Таймкод в чате (`12:34`) перематывает видео у всех.
4. Одинаково работает в браузере, на Android и на компьютере.
5. Интерфейс полностью на русском.

## 4. Минусы похожих сервисов, которые учитываем

- Расширение работает только в одном браузере → у нас сайт и приложения.
- Много рекламы на бесплатном тарифе → у нас рекламы нет.
- Комнаты без входа любой может открыть по ссылке → у нас закрытые лобби доступны только приглашённым.
