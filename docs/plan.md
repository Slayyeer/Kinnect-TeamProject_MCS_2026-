## Как работаем

- Задачи ведём на доске GitHub Projects, у каждой задачи есть ответственный.
- Каждый коммитит под своим аккаунтом; перед `git push` всегда `git pull`.
- Ежедневно короткая встреча: что сделано, что делаю, что мешает.
