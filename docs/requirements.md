# Требования к Kinnect

## 1. Назначение

Приложение для совместного просмотра видео: несколько человек в разных местах смотрят одно видео синхронно и общаются в чате.

## 2. Пользователи

- **Гость** — не вошёл в систему, видит только экран входа.
- **Пользователь** — вошёл и подтвердил почту: заводит друзей, создаёт лобби и заходит в них.
- **Создатель лобби** — пользователь, который создал лобби: выбирает видео, приглашает, может удалять любые сообщения в чате.

## 3. Функциональные требования

### 3.1. Аккаунт
| № | Требование |
|---|---|
| Ф1 | Регистрация по почте и паролю; пароль не короче 8 символов, с буквами и цифрами, вводится дважды |
| Ф2 | Подтверждение почты письмом; без подтверждения доступ к данным закрыт |
| Ф3 | Восстановление пароля по почте |
| Ф4 | Профиль: ник, смайл или фото, цвет |
| Ф5 | Смена пароля и удаление аккаунта |

### 3.2. Друзья
| № | Требование |
|---|---|
| Ф6 | Поиск пользователя по нику или коду |
| Ф7 | Заявка в друзья, принятие и отклонение |

### 3.3. Лобби
| № | Требование |
|---|---|
| Ф8 | Создание лобби: название, открытое или закрытое |
| Ф9 | Приглашение друзей в лобби |
| Ф10 | Список участников и кто сейчас в сети |

### 3.4. Видео и синхронизация
| № | Требование |
|---|---|
| Ф11 | Видео по ссылке: YouTube, Rutube, VK Видео, прямая ссылка (`.mp4`, `.webm`, `.m3u8`) |
| Ф12 | Свой файл: каждый выбирает у себя копию, синхронизируется только управление |
| Ф13 | Пуск, пауза и перемотка у одного участника повторяются у всех |
| Ф14 | Новый участник попадает на текущую секунду видео |
| Ф15 | Запоминание места, где остановились |

### 3.5. Чат
| № | Требование |
|---|---|
| Ф16 | Сообщения в реальном времени |
| Ф17 | Смайлы, стикеры, реакции на сообщения |
| Ф18 | Таймкод в сообщении (например, `12:34`) перематывает видео у всех |
| Ф19 | Правка и удаление своих сообщений |

## 4. Нефункциональные требования

| № | Требование |
|---|---|
| Н1 | Задержка синхронизации между участниками — не больше 0,5 с |
| Н2 | Платформы: браузер, Android 7.0 и выше, Windows (также macOS и Linux) |
| Н3 | Интерфейс на русском языке, понятные сообщения об ошибках |
| Н4 | Данные доступны только вошедшим пользователям с подтверждённой почтой; чат лобби — только его участникам |
| Н5 | Пароли и ключи не хранятся в репозитории |
| Н6 | Работа в пределах бесплатных тарифов (Firebase, Cloudflare) |
| Н7 | Удобство на телефоне: интерфейс подстраивается под узкий экран |

## 5. Ограничения

- Видеофайлы не загружаются на сервер (хранилище файлов в Firebase платное).
- Защищённые видео (DRM, платные подписки) не поддерживаются.
